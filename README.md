# Restaurant Page

Restaurant page developed as part of the JavaScript path of [The Odin Project](https://www.theodinproject.com/paths/full-stack-javascript/courses/javascript), with a focus on **modular JavaScript** and **dynamic DOM rendering** using **Webpack** bundling.

## Project Objective

The main objective was to practice:
- Organizing code into multiple ES modules
- Separating responsibilities by interface section
- Rendering the page content entirely with JavaScript
- Tab navigation (Home, Menu, and Contact) without reloading the page
- Using Webpack to bundle JavaScript, CSS, HTML, and images

## What is it?

A restaurant web application with three main sections:
- **Home**: restaurant presentation, hours, and location
- **Menu**: list of items with name, price, and ingredients
- **Contact**: contact details for reservations, business, and administration

## How to use

1. Enter the project folder: `Javascript/top-restaurant-page`
2. Install the dependencies:
   `npm install`
3. Generate the development build:
   `npx webpack`
4. Open `dist/index.html` in the browser

Optional (development with automatic updates):
- `npx webpack --watch`
- `npx webpack serve`

## Features

- **Tab navigation**: dynamic switching between Home, Menu, and Contact
- **Modular content**: each tab is generated by a separate JavaScript module
- **Dynamic rendering**: content is recreated inside the `#content` element based on the selected tab
- **Active tab indicator**: the selected button receives a highlight class
- **Centralized layout and styles**: CSS imported in the project entry point
- **Webpack build**: processing of HTML, CSS, and image assets

## Code Structure

- `src/index.js`: entry point and tab navigation control
- `src/scriptHome.js`: Home section generation
- `src/scriptMenu.js`: Menu section generation
- `src/contactScript.js`: Contact section generation
- `src/style.css`: interface styles
- `webpack.config.js`: bundling and loader configuration

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES Modules)
- Webpack 5
